## Why

当前岗位管理表单要求用户把自然语言岗位描述拆成多条结构化要求，无法直接承载真实招聘方常用的完整岗位说明。与此同时，页面使用原生下拉框，打开后的系统菜单与纸本橙视觉不一致；工作台固定最小高度还会让空白初始页面立即出现滚动条。

## What Changes

- 将岗位规则输入调整为支持完整段落、编号、分号和多行文本的主输入方式，结构化评估要点保留为可选高级配置。
- 调整评分提示，使 AI 能从完整岗位规则中区分岗位职责、必要条件、优先条件和模糊偏好，并继续输出可引用原文证据的评分结果。
- 新增统一的自定义下拉选择器，替代岗位选择和要求优先级的原生下拉菜单，支持圆润视觉、选中态、键盘操作和点击外部关闭。
- 调整工作台高度为视口自适应：桌面端空白初始页面尽量一屏展示，窗口较矮或内容增多时仍允许自然滚动；移动端保持可滚动布局。
- 保持现有岗位 CRUD、批次评估和结果 API 合同兼容，已有结构化岗位规则仍可编辑和评估。

## Capabilities

### New Capabilities

- `freeform-role-rules`: 定义完整自然语言岗位规则的录入、保存、快照和 AI 评估语义，以及可选结构化要求的兼容行为。
- `custom-select-controls`: 定义岗位选择和优先级选择的自定义下拉交互、可访问性和视觉状态。
- `viewport-fit-workbench`: 定义初始工作台的视口自适应高度、响应式滚动和内容超出时的降级行为。

### Modified Capabilities

无。项目当前没有可同步的主规格目录，本次以三个独立的新能力记录行为契约。

## Impact

- 前端岗位管理弹窗、岗位选择栏、优先级选择控件和工作台布局样式。
- 后端岗位 schema、角色快照和评分提示组装逻辑；不改变现有岗位和批次 API 路径。
- 前端组件测试、后端评分/API 测试和响应式布局验证。
- 不新增数据库、外部服务或供应商 SDK；阿里百炼仍复用现有 AgentScope 兼容接口。
