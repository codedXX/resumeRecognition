## Why

当前工作台已经确定了「纸本橙 / 证据 Diff」方向，但页面仍残留较多英文命令式文案，外框和控件的直角边缘也让整体气质偏硬；同时部分辅助文字只有 9–11px，在中文阅读和移动端浏览时不够舒适。现在需要做一次收口式视觉 refinement，让界面更像中文招聘人员真正会长期使用的审阅工具。

## What Changes

- 将工作台中面向用户的英文标签、命令提示和分区标题统一改为中文，保留 PDF、DOCX、数字和 `+ / - / >` 等必要的技术格式与状态符号。
- 为工作台外框、区域面板、上传区域、证据块、按钮、输入框、筛选器和岗位管理弹窗建立分层圆角体系。
- 放大正文、状态、文件名、候选人元信息、证据引用、按钮和弹窗表单字体，改善中文可读性与移动端触控体验。
- 中文界面优先使用无衬线中文字体，等宽字体仅保留给分数、行号、文件元数据和状态符号。
- 保留当前纸本橙配色、三栏证据层级、响应式结构、键盘焦点和 reduced-motion 行为，不改变后端 API 或评估逻辑。
- 增加组件测试与桌面/移动端视觉验收，确认文案、圆角和字号调整不会造成溢出或破坏信息层级。

## Capabilities

### New Capabilities

- `screening-workbench-readable-ui`: 定义招聘审阅工作台的中文文案、圆角表面、可读字号和字体使用规则。

### Modified Capabilities

无。项目当前没有可同步的主规格目录，本次以独立的前端视觉契约记录 refinement。

## Impact

- 主要影响 `frontend/src/App.tsx`、`frontend/src/styles.css`、`frontend/src/lib.ts` 以及前端组件测试。
- 不修改 FastAPI 路由、数据库模型、上传生命周期、评分提供商或评估结果结构。
- 不增加 UI 框架或字体依赖，继续使用现有本地/远程字体回退链。
- 需要重新运行前端测试、生产构建，并在桌面和移动端检查圆角布局、中文文案和字号可读性。
